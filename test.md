# MD reader Test Document

This is a **test document** for the *MD reader* markdown app.

## Features

### Reading Mode
- Default mode when opening files
- Full-width rendered preview
- Clean, distraction-free reading

### Edit Mode
- Split view with editor on left, preview on right
- Live preview sync
- CodeMirror 6 editor with markdown highlighting
